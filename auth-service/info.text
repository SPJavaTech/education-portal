Option 1: Let Spring Security Handle Login and Write a Success Handler

This is the recommended approach.

Change your SecurityConfig to handle OAuth2 success:

@Configuration
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http, JwtService jwtService) throws Exception {
        http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/auth/**").permitAll()
                .anyRequest().authenticated()
            )
            .oauth2Login(oauth2 -> oauth2
                .loginPage("/oauth2/authorization/github")
                .successHandler((request, response, authentication) -> {
                    OAuth2User oauthUser = (OAuth2User) authentication.getPrincipal();
                    String username = oauthUser.getAttribute("login");
                    String token = jwtService.generateToken(username);

                    response.setContentType("application/json");
                    response.getWriter().write("{\"token\": \"" + token + "\", \"username\": \"" + username + "\"}");
                })
            );

        return http.build();
    }
}


Now when you log in via
http://localhost:9091/oauth2/authorization/github,
you’ll get a JWT response directly.

🔹 Option 2: Keep /auth/callback but Change Redirect

If you want a /auth/callback endpoint:

Tell Spring Security to redirect to your /auth/callback after successful login:

.oauth2Login(oauth2 -> oauth2
    .loginPage("/oauth2/authorization/github")
    .defaultSuccessUrl("/auth/callback", true)
);


Then your callback() method will execute:

@GetMapping("/callback")
public AuthResponse callback(Authentication authentication) {
    OAuth2User oauthUser = ((OAuth2AuthenticationToken) authentication).getPrincipal();
    String username = oauthUser.getAttribute("login");
    String jwt = jwtService.generateToken(username);
    return new AuthResponse(jwt, username);
}
